# ACTIVE WRITING PROFILE｜FQ001《凌晨零点，我接到明天的订单》

purpose: Writer最小稳定身份胶囊；防上下文膨胀与长期漂移。

## 1. Core identity
- 类型：都市脑洞 × 悬疑单元剧 × 城市群像；不是纯刑侦、规则怪谈、灵异、无脑系统爽文。
- 核心承诺：每个订单都是“未来已发生、现在未发生”的谜题；读者持续追三层——本单真相、改写代价、订单来源。
- 世界质感：现代城市真实运转；夜班、医院、道路、物业、司机、跑腿、制度摩擦都应像现实。超常只开一扇小口。

## 2. POV / protagonist
- 第三人称限知陈渡，不越过他的认知。
- 陈渡28岁，夜间跑腿员/曾做即时配送调度；强项是路线感、城市熟悉度、观察与临场判断，不是天才侦探。
- 缺陷：厌恶不可控风险，习惯把人和事拆成配送问题，情感表达差。
- 成长方向：从只保住自己的生活，到愿意为选择承担后果。
- 理性主要通过选择、代价、误判表现，不通过长清单证明聪明。

## 3. Prose identity
- 克制悬疑、现代、具体、有空气；不是报告、备忘录、实验记录。
- 短句是撞击工具，不是默认排版；动作/空间允许中长句流动。
- 避免反复“不是X，是Y”“没有X，只Y”“一个…另一个…”等模板。
- 不追求每句金句；自然句也要有具体对象、动作或感知。
- 不用故意错字/粗糙伪装人类。

## 4. Scene identity
- 主要场景必须有目标、阻力/不确定、会改变后续的选择，以及至少一个非功能性真人/物件/身体细节。
- “问问题→获得精确答案”默认重构。
- 专业信息只有在改变选择/风险/人物/伏笔/现实摩擦时才保留。
- 临时角色有自己的忙、怕担责、赶时间、利益、误解，不做搜索引擎。

## 5. Suspense / emotion
- 单章尽量兼有curiosity、suspense、surprise，不只不断新增未知名词。
- 章末必须改变状态，不总结中心思想。
- 情绪优先通过身体、行为、关系、选择表达；克制不等于无情绪。
- 每章至少偿还一笔旧承诺，再建立下一步期待。

## 6. System boundaries
- 明日达不给“正确答案”；新增规则必须经Canon变更。
- 未来信息有价值但不完整；改写未来会迁移风险，不保证善果。
- 不允许临时新增系统功能替主角解围。
- 现实权限优先：普通人不应无理由获得后台、医疗、警方、车辆等受限信息。

## 7. Current anti-pattern blacklist
- 查询→电话→精确回答→记录→总结的流水线；
- 地图/时间表/变量表连续堆叠；
- 每章都靠倒计时；
- 陈渡永远正确、其他人降智；
- NPC只为解释设定；
- 高压无余波；
- 连续几章同一种争执/同一种钩子；
- 作者替读者解释已经看懂的因果。

## 8. Evolution rule

# Story Bible｜《凌晨零点，我接到明天的订单》

## 一句话卖点
夜间跑腿员陈渡每天零点会收到一张来自24小时后的订单；第一单的收件人是他自己，配送地址却是市殡仪馆，物品是一张写着他名字的死亡证明。

## 核心阅读承诺
每个订单都是一个“未来已经发生、现在尚未发生”的谜题。陈渡必须在不知道完整因果的情况下决定送不送、怎么送，并承担改写未来后的连锁后果。读者持续获得三层期待：本单真相、本次改写代价、订单来源终极谜团。

## 题材定位
都市脑洞 × 悬疑单元剧 × 小人物逆袭 × 城市群像。爽点来自信息差、临场决策、反转验证和能力升级，不依赖无脑打脸。

## 主角发动机
- 主角：陈渡，28岁，夜间跑腿员，曾做即时配送调度。
- 欲望：先活下来，再搞清楚是谁在操纵他的明天。
- 核心优势：路线感、城市熟悉度、临场判断、观察力；不是天才侦探。
- 超常工具：旧手机上的“明日达”订单。
- 缺陷：高度厌恶不可控风险，习惯把人和事当作配送问题拆解，情感表达差。
- 成长：从“只想把自己的生活送到终点”到“敢为选择承担后果”。

## 明日达规则 v1
1. 每天 00:00 后出现来自约24小时未来的一张订单；早期通常每日最多1单。
2. 订单包含：取件点、物品、收件人、送达点、截止时间；不解释原因。
3. 只有陈渡能读取订单正文；他人看到的是普通离线界面，截图/录屏无法保留异常信息。
4. 订单物品不可随意替换；替换会导致签收失败。
5. “签收”与“偏差结算”是两个阶段：满足订单的物理/结果条件后先进入“已签收”；若订单来源未来时点尚未到达，则界面显示“待结算”。
6. 当订单来源所对应的未来时点经过后，系统结算“偏差率”，表示现实相对该来源未来发生了多大改变，但不告诉好坏；若来源时点在签收前已经经过，则签收后可立即结算。
7. 连续完成并结算订单会提升“未来信用”，逐步开放更长预览窗口、局部提示或额外订单；这不是金钱奖励。
8. 订单不是善意保证。未来发送者可能追求与陈渡不同的目标。
9. 未完成订单不会直接惩罚陈渡，但未来会按新的现实重算，可能产生更坏结果。
10. 任何对规则的新增解释都必须经过 Canon 变更，不得临章方便式补设定。

## 冲突引擎
“知道结果但不知道因果”是每个单元的发动机。陈渡拥有信息优势，却永远缺少完整信息：送达可能救人，也可能成全更糟的未来。随着能力升级，他从解决单点危机进入多目标冲突，最终面对“哪一种未来值得被保留”。

## 升级循环
订单出现 → 识别异常 → 查找因果 → 选择介入方式 → 现实偏移 → 签收/失败 → 得到新规则或新线索 → 更高难度订单。

## 防重复约束
- 连续3个单元不得使用同一种危机类型。
- 订单功能轮换：递送 / 取回 / 转交 / 延迟 / 无接触投递 / 护送。
- 至少20%的订单结局不是纯正收益。
- 至少每15章出现一次“订单内容本身值得怀疑”的剧情。
- 至少每30章改变一次故事尺度或游戏规则。

## 长线终局
陈渡逐渐确认：明日达并非来自唯一未来，而是来自多个互相竞争的未来分支。城市中存在第二名“收单人”，其任务不是完成订单，而是让某些订单永远无法送达。终局不是消灭某个坏人，而是决定人是否有权用少数人的代价锁死多数人的未来。

# Style Bible｜FQ001

version: 2.0
updated: 2026-10-08

## 1. 基调
现代城市、夜色与白昼的运行系统、真实职业质感、克制悬疑。超常只开一扇小口，周围世界必须像真实城市一样有噪声、有疲惫、有利益、有误差。

## 2. 视角
第三人称限知，以陈渡为主。
- 不越过他的认知边界；
- 不用“他不知道的是”偷发信息；
- 不把作者的结构分析直接塞进陈渡脑中；
- 陈渡善于拆变量，但他的注意力也会被疲劳、钱、尴尬、危险和人打断。

## 3. 陈渡的文字声音
陈渡本人：短、实用、先找可操作问题；紧张时更冷。
叙事声音：不能等同于陈渡备忘录。小说要比他的脑内表格更有空气。

表现理性优先顺序：
1. 他做了什么选择；
2. 选择造成什么后果；
3. 他忽略/误判了什么；
4. 必要时才用一句总结。

禁止用十条清单证明他聪明。

## 4. 段落与句子
- 短句是撞击工具，不是默认排版。
- 动作/空间可用中长句形成流动；危险瞬间再收短。
- 连续3个以上极短段必须有明确节奏目的；否则合并或改写。
- 同章反复“不是X，是Y / 没有X，只Y / 一个…另一个…”触发Editorial风险。
- 不强行追求“每句话都金句”；自然句、过渡句也要有具体对象和动作。
- 不故意加语病、错字或粗糙来伪装“人类”。

## 5. 场景原则
每个主要场景至少有：
- 一个具体目标；
- 一个阻力或不确定；
- 一个会改变后续的动作/选择；
- 一个非功能性但有记忆点的人/物/身体细节。

如果一场戏只完成“问问题→得到答案”，优先重构。

## 6. 专业信息
职业细节是悬疑工具，不是展示知识。
保留条件：至少满足一个——
- 改变陈渡选择；
- 改变风险；
- 揭示人物；
- 构成伏笔/反转；
- 制造现实摩擦。
否则删/压缩。

## 7. 对话
### 陈渡
话少、问题准，但不能每句话都是审讯。

### 老马
碎嘴、现实、会开损话；是同行关系，不是搜索引擎。

### 顺驰司机
有自己的工作便利、麻烦与判断；“168”这种称呼体现他把陈渡当真人看。

### 许知微
医学式精确，讨厌未经验证的推断；她会反驳而非配合陈渡。

### 顾行舟
礼貌、完整、擅长从结果倒推正当性；危险来自价值观，不靠大声威胁。

### 临时角色
必须有局部注意力和优先级：忙、困、怕担责、赶下班、嫌麻烦、误会、好奇等。不能自动给标准答案。

## 8. 情绪
克制不是无情绪。
优先写：
- 身体：口干、疲劳、手上动作改变、胃口、睡眠；
- 行为：多做一步、少问一句、突然不接玩笑；
- 关系：避开解释、被人看穿、欠人情、误会；
- 选择：本可以更安全，却因某个价值判断做另一件事。

少用“他很害怕/他意识到/他终于明白”直接声明。

## 9. 悬疑
区分：
- curiosity：过去/机制到底怎么回事；
- suspense：接下来会不会发生坏结果；
- surprise：新事实迫使读者改写原判断。

同一章不应只有curiosity。尤其首单死亡线必须让读者同时担心陈渡的结果。

## 10. 章末
章末应改变状态，而不是提炼主题。
优先：新事件、不可撤回选择、意外代价、关系变化、规则反常、迫近危险。
连续两章不得同构成“陈渡写下一句结论→发现变量又变了”。

## 11. 留存
- 开头尽快给明确问题/动作；
- 中段若连续只有信息新增，没有事件/选择/人物变化，重构；
- 每章至少还一笔旧承诺；
- 新钩子不能只靠再加一个未知名词；
- 真正平台数据一旦有，优先看章节读完率、跟读与评论。
